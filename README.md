# Delta System

A versatile FiveM script for managing player values with ESX integration.

## Features

- Manages player values with ESX integration
- Updates and retrieves player values from a database

## Requirements

- FiveM server with ESX framework
- MySQL database

## Installation

1. Download the script files.
2. Place the files in your FiveM server's resources folder.
3. Add `ensure DeltaSystem` to your server.cfg file.

## Usage

- Press the E key to update your player value.
- The script will display your updated value.

## Configuration

- `Config.Database.TableName`: The name of the database table.
- `Config.Settings.EnableDebug`: Enable or disable debug mode.
- `Config.Settings.DefaultValue`: The default value for new players.
